SKY CLASH V54.1 — MIXAMO SKELETON ROTATION FIX
================================================

INSTALL: Requires V54 (already installed). Upload the included index.html,
js/game.js and src/41-mixamo-animations.js, preserving their exact relative paths.
Replace matching files; do not delete or overwrite fighter VRMs.

CAUSE: V54's offline FBX baker used intrinsic XYZ Euler rotations, but
Mixamo FBX PreRotation/animated channels require extrinsic xyz. That caused
about 106 degrees of bind-pose orientation error in both shoulder chains,
resulting in severe unnatural twists and inside-out-looking motion.

FIX: All 28 clips were regenerated with the correct FBX rotation convention.
An explicit source FBX BindPose validation now checks shoulder, elbow and leg
rest axes, and a new runtime sampling regression checks elbow hinge axes.

Rebuilt js/game.js from corrected sources; index.html now uses ?v=541
to bust GitHub Pages browser cache. Other gameplay remains the same.

TEST: Automated and bind-pose tests passed, but we cannot certify a full
visual browser playthrough in this environment. If any particular clip is
still visually off, note its name in the DOJO Animation Testing Room.

VRM files, fighter identities and prior V53 permissions are unchanged.
