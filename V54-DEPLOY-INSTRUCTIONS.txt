SKY CLASH V54 — RECORDED COMBAT / ANIMATION TESTING ROOM
========================================================

This is a GitHub UPDATE ZIP, not a full replacement project.

PREREQUISITE
Your GitHub repo must already contain the earlier V53 upload,
preferably V53-GitHub-Update-Permissions-Fixed.zip. This update does NOT
contain assets/rin.vrm or assets/fighter.vrm. It deliberately keeps the
corrected Rin model and its approved permissions untouched.

UPLOAD TO GITHUB
1. Open https://github.com/Theo524/sky-clash
2. Extract V54 ZIP on your Windows computer.
3. Add/replace its contents at the same relative paths in the repository.
   In particular, replace index.html and js/game.js, and upload each
   changed src/ file. Do not put everything inside an extra folder.
4. Commit. After GitHub Pages deployment, refresh with Ctrl+F5.

WHAT CHANGED
- 28 selected FBX motions from user-provided boxing/kicking/ninja/capoeira
  assets were baked offline to compact quaternion data (no raw FBX).
- Selected real animation tracks used for Kairo's jab/cross/hook and kick,
  and Rin's palm/elbow/spin, while retaining V53 choreography for the
  rising kick, aerial uppercut, Meteor Kick and Falling Fist.
- Attack keyframes map to existing physical hit contact timing; transitions
  crossfade to/from prior animations. Physics, damage and combos unchanged.
- Source starting orientation is neutralized to the gameplay heading;
  source turns and spins are preserved within each clip.
- Fighter-specific idle motion and simple recorded evasive footwork.
- Dojo > DOJO button > "Animation testing room" to preview all 28 imported
  motions directly on your selected fighter. Preview is visual only.
- Original V53 Rin masks, face, eyes, jump and unique sprint retained.

IMPORTANT
This is a FIRST gameplay integration of the Mixamo recordings, not the
final animation polish. Visual retargeting/foot IK could not be verified in
this environment. The dojo preview tool is included specifically to catch
moves that look too fast, rotated, ungrounded or mismatched on your VRM.

The synchronized two-person MMA double-leg takedown has NOT been included:
only the attacker FBX is available, with no aligned victim animation.

TESTING
All existing Node/structural regression tests and new V54 baked-animation
sampling tests pass. Browser visual QA was attempted but local Chromium
navigation was blocked by the execution environment (ERR_BLOCKED_BY_ADMINISTRATOR).

RIGHTS
Source: Mixamo motion files uploaded by the game author. Only baked motion
tracks required by the game are deployed; raw FBX files aren't shipped.
Adobe Mixamo and VRoid licensing/terms remain applicable to the assets.
